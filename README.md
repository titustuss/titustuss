> ![Client Side](/assets/ClientSide.png)

- ### Public Directory
  > Resource Images

## Server Side

> ![Server Side](/assets/ServerSide.png)

- ### Models Directory
  > Stores MongoDB Models

- ### Utils Directory
  > Cloudinary Configuration Files

- ### Index.js
